# 기상청 남한상세 1 km 다운로드 목록 (기후변화 상황지도, 2026-09-02 확인)

다운로드는 **로그인 필수**(아이디/비밀번호 계정, climate.go.kr/atlas/auth/login → 회원가입 가능).
다운로드 버튼을 누르면 소속·활용분야·사용목적 설문 창이 뜨고, 제출 후 파일이 내려온다.
포털 URL: https://climate.go.kr/atlas/ana/cdd — 왼쪽 필터에서 **남한상세 › 격자 › 기후요소**를 체크하고
카드 안의 요소 라디오에서 **최고평균기온**을 고른다. 아래 표의 `ds`/`file`은 다운로드 버튼의
`data-dataset-id` / `data-file-id` 값이라 행을 찾는 데 쓸 수 있다.

받은 파일(tar.gz 그대로)은 `~/climada/data/kma/` 에 넣는다. 그 뒤:

```bash
./.climada-env/bin/python scripts/heat_korea.py files      # 체크 표시 확인
./.climada-env/bin/python scripts/heat_korea.py register   # 카탈로그 등록
./.climada-env/bin/python scripts/heat_korea.py run        # 데모 포트폴리오 실행
```

## 용량 계획

파일 크기는 로그인 전에는 보이지 않는다. 1 km 격자 × 10년 일자료는 **비압축 약 6.6 GB/파일**
(751×601×3,653일×4바이트)이고 NetCDF 압축이 걸려 있으면 1–3 GB로 줄어든다. 현재 디스크 여유는
**24 GB**이므로 17개 파일을 한 번에 두는 것은 불가능하다. 권장 운영:

1. 파일을 **한두 개씩** 받아 `~/climada/data/kma/`에 두고 `register`를 돈다.
2. `register`가 끝난 원본 tar.gz/nc는 지우거나 iCloud Drive
   (`~/Library/Mobile Documents/com~apple~CloudDocs/climada-kma/`)로 옮긴다. 카탈로그에 남는
   HDF5는 5 km 블록 평균 기준 수십 MB 수준이다.
3. `register`는 창(window) 단위로 독립이라 파일이 도착하는 순서대로 나눠 돌려도 된다.

## 주의 — 앙상블 평균

SSP 파일은 5개 지역기후모델의 **일별 앙상블 평균(5ENSMN)** 하나만 제공된다. 모델별 일자료를
날마다 평균하면 각 모델의 열파가 서로 상쇄되어 극값이 눌린다. 따라서 미래 초과 온도일수(degree-days)는
**하한 추정치**로 읽어야 한다. 과거 MK-PRISM은 관측 기반이라 이 문제가 없다. 카탈로그 `source`
문자열에 "ensemble-mean daily fields: extremes damped"로 표기된다.
