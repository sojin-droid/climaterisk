# 국내 홍수 방어시설 자료 조사 — 위치별 방어 수준을 정할 수 있는가

작성 2026-10-14. 웹 조사만 했다(파일 다운로드·회원가입·인증키 입력 없음). "확인"은 2026-10-14에 데이터셋
페이지를 직접 열어 본 것이고, data.go.kr 파일 페이지 대부분은 실제 열·행을 볼 수 없어 **행 값은 보지 못했다.**

> **TL;DR (EN).** No open, nationwide, georeferenced layer of levees, sea walls or pump stations with a
> design return period exists that can be used commercially. The national SHPs closest to it are 공공누리
> 제4유형 (no commercial use / no modification). Until site-level data is connected, the Models tab
> applies one **national design return period per flood hazard** (`physical_risk_config.json` →
> `flood_protection`: river 50 y, coastal 50 y — the lowest documented standard, so protection is never
> overstated) and reports the undefended EAL beside it.

## 1. 왜 필요한가

두 홍수 하자드 모두 방어시설이 없다고 가정한다. 하천홍수(ISIMIP)는 한강·안양천 제방과 빗물펌프장을,
해안침수(WRI Aqueduct)는 방조제·호안을 반영하지 않는다. OSM 1,000동 실행에서 시화·반월, 남동, 군산
매립지의 공장은 2년 빈도부터 4–5 m 침수되어 EAL이 자산가치의 연 45–48 %로 나왔다
([sample-portfolio-1000.md](sample-portfolio-1000.md) §5).

## 2. 지금 적용한 규칙 (전국 일괄)

| 하자드 | 설계빈도 | 근거 |
|---|---|---|
| 하천홍수 (RF) | **50년** | 「하천기본계획 수립지침」(환경부고시, 2023.10.31) §4.1 하천의 계획규모: A급 200년 이상, B급 100~200년, C급(지방하천) 50~200년. 과거 관행 지방하천 50년 / 국가하천 100년(KDI 2002). 하한을 써서 방어를 과대평가하지 않는다. 한강 등 A급 구간은 실제로 훨씬 높다 |
| 해안침수 (CF) | **50년** | 항만 외곽시설(방파제) 설계파 50년 → 2021-11-08 주요 무역항 100년 상향(언론 보도; KDS 64 조문 미확인). 방조제의 설계빈도는 찾지 못했다(새만금 방조제 자료는 설계파고·설계수위·여유고만). 상향 전 값을 쓴다 |

규칙: 격자마다 설계빈도 침수심(CLIMADA `local_exceedance_intensity`, stepfunction) 이하의 이벤트는 0,
넘는 이벤트(월류)는 전체 침수심. 방어 미적용 EAL(`eal_undefended_usd`)과 "방어 없이 2년 빈도에도
잠기는 격자"(`undefended_frequent_flooding`)를 행마다 함께 기록한다. 코드:
[`protection.py`](../worker/climaterisk_worker/physical_risk/protection.py).

참고 기준(조사 결과, 일괄값으로는 쓰지 않음): 하수도설계기준 KDS 61 10 00:2022 — 빗물펌프장 최소 30년,
상향 시 50년(2022.1 개정); 지역별 방재성능목표(자연재해대책법 §16-4) 50년 상향 보도.

시화·남동·군산 같은 대규모 매립지 경계의 공개 폴리곤, 해양수산부 호안·연안 방재시설 목록.

## 4. 다음 단계 (추천 순)

1. **펌프장 자료 통합** — 시도·시군구 "재난대응용 배수펌프장 현황" 파일(인증키 불필요)과 서울 빗물펌프장
   공간정보를 모아 주소를 좌표로 바꾸고, 행마다 `계획빈도(년)`(없으면 KDS 61 최소 30년)를 쓴다. 보호 구역이
   공개돼 있지 않으므로 펌프장 주변 저지대를 근사로 써야 하고, 그 근사를 결과에 표시한다. 내수침수
   하자드가 없는 한 이 자료는 **하천홍수의 방어 수준 보정**과 리포트의 "주변 방어시설" 표시에 쓴다.
2. **하천 등급별 설계빈도** — WAMIS 하천시설 CSV의 열을 확인하고, 국가하천/지방하천 구분으로 지침 표(A 200+,
   B 100–200, C 50–200)를 하천 구간에 붙인다. 계획홍수위·제방 선형은 RIMGIS 계정 신청이나 정보공개청구가
   필요하다.
3. **KHOA 연안침수 API** — data.go.kr 인증키를 **사용자가** 신청해야 한다(개발계정 자동승인). 활용가이드(HWP)로
   형상 형식과 방조제 반영 여부를 확인한 뒤 Aqueduct의 검증 또는 대체 자료로 쓴다. 공공누리 1유형이라 상업
   이용이 가능하다.

OSM 방어시설(펌프장 약 70곳, 수문 수백, '방조제' 이름 선 100여 개 — 다수가 "방조제길" 도로명)은 실제보다
훨씬 적고 보호 범위를 담지 않아 계산에는 쓰지 않는다.
