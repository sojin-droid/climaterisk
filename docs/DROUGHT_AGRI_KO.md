# 농업 가뭄 손실 평가 — 방법 노트 (전국, 시군구)

상태: **초안 (2026-11-10)**. 데이터 확보 + 방법 정의 단계이며 코드는 아직 없다.
공간 단위는 시군구(KRC 자료는 167개 시군 단위), 시간 단위는 월(위해)·연(손실)이다. 10 m 필지 해상도는 쓰지 않는다.
원자료는 저장소 밖 `<DATA_ROOT>/external/drought/`에 있고, 출처마다 `manifest.json`이 있다(§6).
"확인함"은 이번 작업에서 원문 페이지나 파일을 직접 읽었다는 뜻이고, **[미확인]**은 그렇지 않다는 뜻이다.

## 1. 왜 토지 유형별로 위해를 나누는가

국내 연구에서는 강수 기반 가뭄지수와 벼 수량의 상관이 약하다. 논은 대부분 관개되기 때문이다
(Woo et al. 2021, 한국농공학회논문집 63(5); Park et al. 2022, r ≈ −0.26). 그래서 위해 변수를 이렇게 나눈다.

| 토지 유형 | 위해 변수 | 근거 |
|---|---|---|
| **논** (수리답) | 농업용 저수지 시군 통합저수율의 **평년 대비 비율** | 관개 용수 부족이 실제 피해 경로다 |
| **논** (수혜구역 밖·천수답) | SPEI-3 (밭과 같은 방식) | 저수지가 없으면 강수·증발산이 지배한다 **[가정 A3]** |
| **밭** | SPEI-3, 5–9월 종료월 | 천수(빗물) 의존 |
| **과수** | SPEI-3, 5–9월 종료월 (+ SPEI-6 참고) | 다년생이고 뿌리가 깊다. 장기 누적 지수를 함께 본다 |

### 1.1 논 — 저수율 평년비

$$R_{s,t} = 100 \cdot \frac{S_{s,t}}{\bar S_{s,\mathrm{doy}(t)}}$$

ASCII: `R[s,t] = 100 * S[s,t] / S_normal[s, doy(t)]`

- $S_{s,t}$: 시군 $s$, 날짜 $t$의 통합저수율 (%, 유효저수량 대비)
- $\bar S_{s,\mathrm{doy}}$: 같은 날짜의 평년 저수율 (%). KRC가 계산해 제공한다
- $R_{s,t}$: 평년 대비 비율 (%)

단계 기준 (KRC 농업가뭄 예·경보 기준, data.go.kr 15117185 설명문에서 확인함):

| 단계 | 평년비 $R$ |
|---|---|
| 관심 | ≤ 70 % |
| 주의 | ≤ 60 % |
| 경계 | ≤ 50 % |
| 심각 | ≤ 40 % |

연 지표는 영농기(4–9월) 중 $\min_t R_{s,t}$와 각 단계에 머문 일수로 만든다 **[가정 A4]**.

### 1.2 밭·과수 — SPEI

**TerraClimate v1.1 월 강수($P$)와 Penman–Monteith 기준증발산($ET_0$)으로 SPEI를 직접 계산한다**(1/24°, 1981–2025, §6).
처음에는 CHC가 0.05°로 미리 계산해 둔 SPEI(CHIRPS3 + Hobbins/MERRA-2 RefET)를 받으려 했다. 그러나 수집 도중 서버가 요청을 거부해(HTTP 429 → 403, 이후 응답 없음) 받지 못했다.
CHC 제품은 접근이 회복되면 교차 확인용으로 쓴다. 정의는 아래 식과 같다.

$$D_{i,m}^{(k)} = \sum_{j=0}^{k-1}\left(P_{i,m-j} - ET_{0,i,m-j}\right), \qquad \mathrm{SPEI}_{i,m}^{(k)} = \Phi^{-1}\!\left(F_{\mathrm{LL3}}\!\left(D_{i,m}^{(k)};\,\theta_{i,\mathrm{month}(m)}\right)\right)$$

ASCII: `D_k = sum_{j<k}(P - ET0)[m-j];  SPEI_k = PhiInv( F_GEV(D_k; L-moment fit per cell & calendar month over the reference period) )  (2026-11-10: GEV per Stagge et al. 2015 replaces the log-logistic, which is undefined for negatively skewed samples)`

- $P$: 월 강수 (mm/월), $ET_0$: 기준증발산 (mm/월; TerraClimate Penman–Monteith. 정확한 기준면 정의는 TerraClimate 문서에서 확인해야 한다 **[미확인]**)
- $k$: 누적 개월 수 (3 또는 6), $i$: 격자, $m$: 종료월
- $F_{\mathrm{LL3}}$: 3모수 log-logistic 누적분포. 격자·종료월별로 기준기간에 적합한다. 기준기간은 1991–2020으로 한다 **[가정 A11]**. CHC 제품은 1996–2025를 쓴다(CHC README에서 확인함)
- $\Phi^{-1}$: 표준정규 역누적분포. SPEI는 무차원이다

등급 (CHC README와 KMA SPI 단계가 같은 값을 쓴다):

| 등급 | SPEI |
|---|---|
| 보통 가뭄 | −1.0 ~ −1.49 |
| 심한 가뭄 | −1.5 ~ −1.99 |
| 극한 가뭄 | ≤ −2.0 |

시군구 값은 시군구 폴리곤 안 격자의 면적가중 평균이다. 1단계에서는 경지 가중을 하지 않는다 **[가정 A5]**.
교차 확인용으로 SPI-3과 SPI-6도 계산한다(KMA SPI-6 단계와 비교하기 위해서다). 입력은 TerraClimate $P$이고, CHIRPS v2.0은 확보한 1981-01–1992-02 구간에서 비교용으로 쓴다.

## 2. 손실식

### 2.1 밭·과수 — FAO-33 수량반응식

$$1 - \frac{Y_a}{Y_m} = K_y\left(1 - \frac{ET_a}{ET_m}\right)$$

ASCII: `1 - Ya/Ym = Ky * (1 - ETa/ETm)`

- $Y_a$, $Y_m$: 실제 수량과 최대(무스트레스) 수량 (t/ha)
- $ET_a$, $ET_m$: 생육기간 실제·최대 증발산 (mm/생육기간)
- $K_y$: 수량반응계수 (무차원)

식의 출처는 FAO-66 2장 식 (1)이다(Doorenbos & Kassam 1979, FAO I&D Paper 33). 원문에서 확인했다.

**$ET_a/ET_m$은 월 단위 토양수분 버킷(FAO-56 단일 계수)으로 계산한다** **[가정 A6]**:

$$ET_m = K_c\,ET_0,\qquad ET_a = K_s\,K_c\,ET_0,\qquad K_s = \begin{cases}1 & D_r \le RAW\\[2pt] \dfrac{TAW - D_r}{(1-p)\,TAW} & D_r > RAW\end{cases}$$

$$TAW = 1000\,(\theta_{FC}-\theta_{WP})\,Z_r,\qquad RAW = p\,TAW,\qquad D_{r,m} = \min\!\big(TAW,\ \max(0,\ D_{r,m-1} - P_{e,m} + ET_{a,m})\big)$$

ASCII: `ETm = Kc*ET0; ETa = Ks*Kc*ET0; Ks = 1 if Dr<=RAW else (TAW-Dr)/((1-p)*TAW); TAW = 1000*(thFC-thWP)*Zr; RAW = p*TAW; Dr[m] = clip(Dr[m-1] - Pe[m] + ETa[m], 0, TAW)`

- $K_c$: 작물계수 (무차원), $K_s$: 수분 스트레스 계수 (0–1)
- $TAW$, $RAW$: 총·쉽게 이용 가능한 토양수분 (mm)
- $\theta_{FC}$, $\theta_{WP}$: 포장용수량과 위조점 체적함수율 (m³/m³), $Z_r$: 유효 근권 깊이 (m)
- $p$: 스트레스 없이 고갈 가능한 비율 (무차원), $D_r$: 근권 고갈량 (mm)
- $P_e$: 유효 강수 (mm/월). 입력은 TerraClimate $P$이다. 유효강수 공식은 미정이다
- 버킷을 만들기 전 1차 근사로 TerraClimate 자체 물수지의 $AET/PET$를 $ET_a/ET_m$ 대리값으로 쓸 수 있다. 다만 이 값은 기준면(잔디) 기준이라 작물 $K_c$를 반영하지 않는다 **[가정 A6b]**
- 생육기간 합: $ET_a/ET_m = \sum_m ET_{a,m} / \sum_m ET_{m,m}$

SPEI는 위해 지도와 단계 판정에, 버킷 $ET_a/ET_m$은 손실 계산에 쓴다. 둘은 같은 $P$·$ET_0$에서 나오므로 서로 어긋나지 않는다.

### 2.2 금액 환산

$$L_{s,y} = \sum_{c} A_{s,c,y}\; Y_{m,s,c}\; p_{c,y}\; \underbrace{K_{y,c}\left(1-\frac{ET_a}{ET_m}\right)_{s,c,y}}_{\text{손실률},\ [0,1]로\ 절단}$$

ASCII: `L[s,y] = sum_c A[s,c,y] * Ym[s,c] * price[c,y] * clip(Ky[c]*(1-ETa/ETm)[s,c,y], 0, 1)`

- $L$: 시군구 $s$, 연도 $y$의 손실 (원/년). `pint` 단위는 `KRW`
- $A$: 작물 $c$의 재배면적 (ha), $Y_m$: 무스트레스 수량 (t/ha). 대리값은 평년작 수량이다 **[가정 A7]**
- $p$: 단가 (원/t) **[출처 미정]**

### 2.3 논

FAO-33 표 1에는 벼의 계절 $K_y$가 없다(§3). 그래서 1단계에서는 FAO-33 식을 논에 쓰지 않는다.
대신 **단계별 피해율 곡선**을 둔다.

$$L^{\text{논}}_{s,y} = A^{\text{수리답}}_{s}\,Y_{m,s}\,p\; f\!\left(\min_{t\in \text{4–9월}} R_{s,t}\right) + L^{\text{천수답}}_{s,y}$$

ASCII: `L_paddy = A_irrigated * Ym * price * f(min R over Apr-Sep) + L_rainfed(SPEI path)`

- $f(\cdot)$: 평년비에서 피해율로 가는 계단함수. 단계별 값은 **아직 없다**. §5의 검증 사례로 보정한다 **[가정 A8]**.
  보정 전에는 결과를 "단계 노출 면적(ha)"으로만 보고하고, 금액은 내지 않는다.
- $L^{\text{천수답}}$: 수혜구역 밖 논. §2.1 경로에 벼 $K_y$를 넣어 계산한다. 벼 $K_y$가 확보되기 전까지는 비워 둔다.

절차:
1. **위해 단계 일치**: 2025년 KRC 논가뭄지도 단계(일별 시군)와 우리가 재계산한 $R$ 단계가 같아야 한다(정의가 같으므로 사실상 자료 검증).
2. **사건 탐지**: 시군구-연 단위로 "피해 보고 있음/없음"(통계집 2018–2021+)과 "SPEI-3 ≤ −1.5 또는 $R$ ≤ 60 % 도달"을 비교한다.
   적중률·오경보율·Heidke skill score를 쓴다.
3. **규모**: 피해면적과 모형 노출면적의 순위상관(Spearman)을 본다. 표본이 적으므로 금액 보정은 하지 않고, $f(\cdot)$의 단계값만 보정한다.
4. **사례**: 2022 전남. 6–9월 시군별 $R$·SPEI 궤적과 피해 보고 시군을 대조한다.
