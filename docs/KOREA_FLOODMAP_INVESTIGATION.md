# 환경부 홍수위험지도 — `KOREA_LOCAL` 홍수 어댑터 연결 가능성 조사 (Phase 4)

조사일 2026-09-23. 목적: `KoreaLocalFloodAdapter`(현재 `NOT_IMPLEMENTED`)를 실제 국내 홍수위험지도에
연결할 수 있는지 — **데이터 접근권 · 라이선스 · 파일 구조 · 공간좌표 · 침수심 · 재현기간** — 을 먼저 확인한다.
구현은 하지 않았다. 아래 사실은 포털 페이지와 **구조 확인용 샘플 2개(0.9 MB, 8.4 MB)**에서 직접 읽은 것이며,
샘플은 스크래치 디렉터리에만 두고 저장소·데이터 디렉터리에 넣지 않았다.

## 결론 먼저

| 항목 | 결과 | 어댑터에 미치는 영향 |
|---|---|---|
| 접근권 | **로그인 불필요**, `data.floodmap.go.kr` 목록·다운로드 API 공개 | 기술적 장벽 없음 |
| 라이선스 | **공공누리 제4유형 — 출처표시 + 상업적 이용금지 + 변경금지** (포털 저작권 정책 페이지, 공공데이터포털 이용허락범위 모두 동일) | **차단.** 폴리곤을 CLIMADA 해저드 격자로 변환하는 것은 *변경*, 자산 물리위험 평가 서비스는 *상업적 이용*에 해당할 수 있다. 별도 이용허락 전까지 구현하지 않는다 |
| 파일 구조 | SHP(zip), 중권역(`SBSN_CD`) × 빈도 1파일, 각 파일 5행(침수심 등급별 MultiPolygon) | 어댑터 설계에 충분한 정보 확보 |
| 공간좌표 | **EPSG:5186** (KGD2002 / Central Belt 2010, TM, 중앙경선 127°E) | WGS84 변환은 표준 절차 |
| 침수심 | **등급값**(5단계), 연속값 아님 | JRC 수심-피해 곡선을 쓰려면 등급→대표수심 **모델링 결정** 필요 |
| 재현기간 | 국가하천 100/200/500 + 기왕최대; 지방하천 50/80/100/200/500 + 기왕최대; 도시침수 30/50/80/100/500 + 기왕최대 | 확률 해저드로 표현 가능(3–5 RP), 단 "기왕최대"는 RP가 아니다 |

**따라서 `KOREA_LOCAL` 홍수는 `NOT_IMPLEMENTED`를 유지한다.** 코드상 상태 이름은 `NOT_IMPLEMENTED`(어댑터에 데이터가
연결되지 않음)이고, readiness 셀의 `detail`에 차단 사유를 라이선스로 명시했다. UI는 "Korea Local — Not available"로
표시한다.

## 1. 접근권

* 포털: <https://data.floodmap.go.kr> (한강홍수통제소 홍수위험지도 정보제공포털). 로그인·API 키 없이
  `GET /api/shp-file-list/{rv-ntn|rv-rgn|rv-cty}?fileDataSetNm=…` 로 목록, `POST /api/shp/download` 로 파일.
* 공공데이터포털 등록: `data.go.kr/data/15077744/fileData.do` "기후에너지환경부 한강홍수통제소_홍수위험지도_20241231",
  매체 SHP, 전체 행 2,770, 수정일 2025-11-27, 제공형태 "기관자체에서 다운로드".
* 저장소의 `scripts/fetch_floodmap_kor.py`가 이 두 엔드포인트를 그대로 쓴다(**이번 조사에서 실행하지 않았다**).

목록 API 응답(2026-09-23):

| 데이터셋 | 파일 수 | 파일명 패턴 | 예 |
|---|---|---|---|
| 유역별 100년 빈도 국가하천 하천범람지도 | 84 | `RFM_SBSN_NTN_{중권역코드}_{RP}.zip` | `RFM_SBSN_NTN_1022_100.zip` 0.9 MB … `RFM_SBSN_NTN_1101_100.zip` 198 MB |
| 도시침수지도 | 583 | `CFM_SBSN_{중권역코드}_{RP}.zip` | `CFM_SBSN_2012_030.zip` … `_500.zip` |

첫 페이지 10개 파일 합계만 830 MB이므로 100년 빈도 국가하천 84개는 수 GB 규모다.

## 2. 라이선스 — 확인된 문구

포털 저작권 정책(`/main/guide/copyright_policy`):

> 제4유형 [홍수위험지도 해당] — 본 저작물은 "공공누리 제4유형 : 출처표시+상업적 이용금지+변경금지" 조건에 따라 이용할 수 있습니다.

공공데이터포털 이용 조건: "공공저작물 : 출처표시, 상업적 이용금지, 변경금지 (제 4유형)", 비용 무료.

이 플랫폼의 용도에 대한 판단:

| 플랫폼 행위 | 제4유형 조건 | 판단 |
|---|---|---|
| 출처 표시 | 출처표시 | 가능 (`hazard_source`에 기관·데이터셋명 기록) |
| 폴리곤 → 격자 해저드 변환, 등급 → 대표수심 부여, WGS84 재투영 | **변경금지** | 파생저작물에 해당할 가능성이 높다 |
| 자산 포트폴리오 물리위험 평가(EAL·PML)에 사용 | **상업적 이용금지** | 상업 서비스에서는 위반 가능 |

포털 자체 설명도 "지자체의 재해지도 제작, 홍수 관련 보험의 기초자료"를 활용 예로 들지만, 그것이 제4유형 조건을
바꾸지는 않는다. **관리부서(수자원정보센터, 02-590-9977)에 이용허락을 별도로 받기 전에는 어떤 파일도 복사·변환·계산하지
않는다.** 이 조사에서 내려받은 샘플 2개는 구조 확인 후 폐기한다.

## 3. 파일 구조 (샘플 2개에서 직접 읽음)

`RFM_SBSN_NTN_1022_100.zip` (중권역 한탄강, 100년, 국가하천) · `CFM_SBSN_2403_100.zip` (중권역 대종천, 100년, 도시침수)

```
*.shp  *.shx  *.dbf  *.prj  *.cpg          # 한 zip에 shapefile 1세트
```

| 필드 | 형 | 값 (샘플) | 의미 |
|---|---|---|---|
| `SEG_CODE` | text | `N330`, `N331`, `N332`, `N333`, `N334` — **파일마다 정확히 5행** | 침수심 5등급 코드. 등급 정의는 공식 설명의 "0.5m 이하, 0.5~1.0m, 1.0~2.0m, 2.0~5.0m, 5.0m 이상". **코드↔구간 대응(N330 = 최저 등급?)은 포털 어디에도 명시돼 있지 않다 — 추정이며, 관리부서 확인 필요** |
| `FLDLV_FREQ` | text | `100` | 재현기간(년) |
| `SBSN_CD` | text | `1022`, `2403` | 중권역 코드(표준유역코드 데이터셋 `data.go.kr/data/15123324`와 조인 가능) |
| `geometry` | MultiPolygon / Polygon | 등급별 1개 | 침수 범위 |

샘플 수치: 한탄강 100년 — 5 도형, 침수 면적 4.7 km², WGS84 범위 126.999–127.081°E, 37.850–38.007°N.
대종천 100년 — 5 도형, 5.16 km², 129.385–129.459°E, 35.471–36.000°N.

**연속 수심 값은 없다.** 등급 폴리곤만 있다.

## 4. 공간좌표

`.prj`: `PROJCS["KGD2002_Central_Belt_2010", … Transverse_Mercator, Central_Meridian 127.0, Latitude_Of_Origin 38.0,
False_Easting 200000, False_Northing 600000, Scale 1.0, Unit Meter]` → geopandas가 **EPSG:5186**으로 식별.
WGS84(EPSG:4326)로의 재투영은 표준이며, 재투영 후 도형이 CLIMADA 격자(위경도)와 맞는다.

## 5. 어댑터가 만족해야 할 계약 — 라이선스가 풀리면

`docs/korea-hazard-replacement.md` §2·§3의 계약을 이 데이터에 맞춰 구체화한 것. **모두 미구현.**

| 항목 | 이 데이터에서의 구현 방식 | 결정이 필요한 지점 |
|---|---|---|
| `haz_type` / `units` | `"RF"` / `"m"` — JRC 곡선의 x축 | — |
| 강도 | 등급 → **대표수심**(예: 구간 중점 0.25 / 0.75 / 1.5 / 3.5 m, 최상위 등급은 개방구간) | 대표값 선택은 모델링 결정이다. 문서화·감도분석 없이 넣지 않는다. 대안: 등급 하한(보수적) |
| 이벤트 | RP별 1개 — 국가하천 {100, 200, 500} | 3개 RP뿐이라 `calc_freq_curve`의 한계(`max_resolvable_return_period` = 500) 안에서 PML100은 표현 가능. **기왕최대는 RP가 아니므로 제외** 또는 별도 라벨 |
| 빈도 | 초과빈도의 **증분**(플랫폼이 Aqueduct 층에 쓰는 `_incremental_frequency` 규칙) | — |
| 센트로이드 | 폴리곤을 격자로 래스터화(예: 100 m 또는 1 km) 후 격자 중심점; 격자 밖 = 0 | 격자 해상도는 S2·S3 해상도 계약과 함께 결정 |
| 시나리오 | **설계홍수(제방붕괴·월류 가정) 시나리오 — RCP가 아니다.** `served_scenario`에 `"design flood (levee failure assumption), RP set {100,200,500}"`처럼 기록; `requested_scenario`(rcp45 등)와 다르므로 `SCENARIO_MISMATCH`가 되지 않도록 비교 규칙을 정해야 한다 | 기후 시나리오 축이 없는 해저드를 어떻게 세 모델 비교에 넣을지 — 이것이 Phase 4 구현의 핵심 결정 |
| 공간 커버리지 | 중권역 단위 파일 → 포트폴리오 bbox와 겹치는 파일만 로드 | — |
| 출처 | `hazard_source = "환경부 한강홍수통제소 홍수위험지도"`, `hazard_dataset = 파일명`, `hazard_data_version = infoUpdtYm` | — |

한 가지는 지금 말할 수 있다: 이 지도의 "홍수"는 **제방이 실패하는 최악의 시나리오 하에서의 침수 범위**(포털 설명: "실제
하천제방의 안정성과 무관")다. Data API의 ISIMIP 하천홍수(수문 모델 기반 확률 해저드)와는 **다른 종류의 양**이다. 세 모델
비교에서 이 차이는 데이터 차이가 아니라 **정의 차이**로 표시해야 한다.

## 6. 하지 않은 것

* `scripts/fetch_floodmap_kor.py` 실행(대량 다운로드) — 하지 않음.
* 어댑터 구현, 등급→수심 매핑, 래스터화 — 하지 않음.
* `READINESS["RF"]["KOREA_LOCAL"]` 변경 — `NOT_IMPLEMENTED` 유지, `detail`만 확정 문구로 갱신.

## 7. 다음 단계 (라이선스 해결 후에만)

1. 한강홍수통제소 수자원정보센터에 이용허락 요청 — 용도(내부 검증 / 상업 서비스), 변환 방식(격자화·대표수심), 출처표시 방식.
2. `SEG_CODE` ↔ 침수심 구간 대응표를 공식 문서로 확보.
3. §5의 결정 3건(대표수심 · 격자 해상도 · 시나리오 축 처리)을 문서로 확정.
4. 그 뒤 `KoreaLocalFloodAdapter.load()` 구현, `READINESS` → `READY`, `test_adapter_statuses_match_the_backend_readiness_table`이 두 표를 함께 움직인다.
