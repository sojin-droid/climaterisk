# 방법 등록표 설계 (2026-11-16)

## 왜 하나

분석을 여러 번 나눠 하다 보니 같은 재해를 화면마다 다른 방법으로 계산하고 있다. 아래는 2026-11-16 코드와 디스크를 직접 확인한 결과다.

- **하천 홍수:** 자산 평가는 홍수위험지도를 쓰고, 지도 화면은 ISIMIP 격자, Studio는 ISIMIP에 50년 방어를 얹어 쓴다.
- **해안 침수:** 자산 평가는 조위 기준 연결 침수 계산, 지도 화면은 Aqueduct 50번째 백분위, Studio는 Aqueduct 95번째 백분위다.
- **폭염:** 자산 평가는 UTCI, 지도 화면은 폭염일수, Studio는 최고기온 95번째 백분위다.

목표는 재해마다 **전국에 한 가지 주 방법**을 쓰고, 모든 화면이 같은 표를 따르게 하는 것이다. 개별 결과로 되돌아가지 않도록 테스트로 막는다.

## 규칙 (사용자 결정 2026-11-16)

1. **주 방법은 순위로 적는다.**
   - 1순위만 결과로 쓴다.
   - 1순위를 쓸 수 없는 곳은 다른 순위로 채우지 않는다. 값은 NaN이고, 사유를 함께 남긴다.
   - 2순위 이하는 1순위 전체가 쓸 수 없게 됐을 때를 위한 기록이다.
2. **검증 방법도 순위로 적고, 그 순서대로 실행한다.**
   - 검증 결과는 기록만 하고 주 방법의 값을 바꾸지 않는다.
   - 기준을 넘는 차이가 나면 경고한다.
3. **보조 결과는 검증과 따로 둔다.**
   - 디스커션에만 쓴다.
   - 예: 질병청 온열질환자 수. 노출과 적응 수준이 들어 있어 하자드를 검증할 수 없다.
4. **"자료 없음"과 0을 구분한다.**
   - 해당 유역의 지도 파일이 없으면 NaN이고, 사유는 `no_map`이다.
   - 지도가 있는 유역에서 폴리곤 밖이면 0 m다.
5. **한 재해 안에서 지역마다 다른 입력을 섞지 않는다.**
   - 예: 해안 지반고를 국토지리정보원 DEM(2도엽뿐)과 GLO-30으로 섞지 않는다.
   - 섞인 입력은 주 방법에서 빼고 검증으로 옮긴다.

## 무엇을 만드나

1. **`assets/libraries/method_registry.json`**
   - 재해마다 `main`(순위 목록), `checks`(순위 목록), `supplementary`를 둔다.
   - 항목마다 `id`, 설명, 자료, 적용 범위, 쓸 수 없을 때의 처리, 출처를 적는다.
2. **로더 `src/climaterisk/physical_risk/registry.py`**
   - 결과 행마다 `method_id`와 `method_rank`를 적는다.
   - 검증은 등록 순서대로 돌리고, 돈 것과 건너뛴 것(이유 포함)을 기록한다.
3. **테스트**
   - 모든 어댑터와 지도 레이어가 자기 재해의 1순위 `method_id`를 쓰는지 확인한다.
   - 등록표에 없는 방법이 결과에 나오면 실패한다.
4. **지도 없음 = NaN**
   - 표준유역 중권역 경계가 필요하다(디스크에 없음). 공개 자료를 하나 받아야 하고, 받기 전에 출처와 라이선스를 확인한다.
   - 하천 지도는 지방하천 100년 빈도뿐인 유역이 있고, 국가하천 100/200/500년 빈도가 유역마다 다르다. 이 구성을 결과에 함께 적는다.
5. **지도 화면 정렬**
   - **하천 홍수:** 홍수위험지도 폴리곤을 원형 그대로 그린다. 저장, 격자화, 집계는 하지 않고 사용자 컴퓨터 안에서만 본다. ISIMIP 격자는 검증 층으로 내린다.
   - **폭염:** UTCI 층을 만들고 폭염일수 층은 검증으로 표시한다.
   - **해안:** 같은 원칙을 따른다.
   - 외부에 보이기 전에는 수자원정보센터(02-590-9977) 확인이 필요하다.
6. **Studio**
   - 등록표를 따르게 하거나, 따르기 전까지 "다른 방법(참고)"이라는 표시를 단다.

## 이 설계 다음 (따로 진행)

- **폭염 생산성 곡선:** 출처 없는 임시 곡선(2026-06-23, 30 °C 0 % → 45 °C 60 %, 95번째 백분위 기온 기준)을 문헌 곡선으로 바꾼다.
  - IPCC와 해외 학술지를 우선한다.
  - 문헌 곡선은 대부분 WBGT 기준이다. UTCI에 맞추는 방법도 출처로 정당화해야 한다.
  - 정해지면 등록표의 폭염 행에 손실 단계를 추가한다.

## 남은 결정

- 재해연보 시도 피해를 검증으로 쓸지 보조 결과로 쓸지 정해야 한다.
  - 피해액에도 방어 시설과 복구 수준이 들어 있으므로, 질병청과 같은 이유로 보조 결과일 수 있다.
